# 到達那微秒：v5 設計定案

整理日期：2026-09-29。這份文件記錄 v4 之後重新整理、已經定案的設計。v4 的程式還是舊設計（一對多、人生行事歷），v5 會照這份文件改。

## 一句話

用現實中的難題當關卡的合作遊戲。自己想不出辦法的難題，要在約好的那一微秒遇到另一個角色，把兩個難題融合、拆解、分工，直到能算出往後要付出多少熱量。

## 核心定義

- **難題**：原本的角色自己想不出辦法的情況。自己想得出來的，不算難題。
- **完成（可處理）**：能算出往後需要的熱量。每個參與的角色都填完熱量，才算完成。

## 流程

1. **創角色、立難題**：寫下出發點，也就是預定開始處理的時間，精確到微秒。立難題就代表自己想不出辦法。
2. **碰撞**：另一個角色帶著類似的難題寫下同一個出發點，兩邊撞上就融合。
   - 單機：自己開新角色，寫同一個時間。
   - 熟人：靠常用尾數對上。
3. **融合與拆解**：像解二元一次方程式，兩個難題融合成新難題，再拆成幾個階段的挑戰。融合後雙方都能構思。
4. **分工**：
   - 構思者得題點，由另一方發。
   - 執行者得戰點，戰點雙方都可能拿到。
   - 新增或修改階段要全員同意。
5. **判定**：至少雙方共判，有爭議就走爭議處理。
6. **完成**：每個角色填入熱量，全部填完才算可處理。
7. **時間到還沒辦法**：擱置、留下紀錄，必須重創難題（新難題、新出發點，可註明前身）。
   - 還沒遇到第二個角色就到時間：原難題擱置。
   - 已經融合但到時間還沒拆出辦法：新難題擱置，兩個原難題也跟著擱置。
   - 在那一微秒沒人來的角色：同樣擱置、重創。
8. **執行完仍沒解決**：融合難題寫新的出發點，再走一次到達與選擇，加入第三方。三方時題點通用：A 構思一個階段，B、C 各付一份，可以換 B 或 C 的能量點。
9. **退出**：角色可以中途退出。

## 角色序號

- 固定 11 位數，最多 10,000,000,000 個角色。系統第一個角色是 00000000001。
- 縮寫：開頭有幾個 0，就用第幾個英文字母取代。

| 序號 | 開頭 0 的數量 | 縮寫 |
|---|---|---|
| 00000000001 | 10 | J1 |
| 00000000010 | 9 | I10 |
| 00000000100 | 8 | H100 |
| 01000000000 | 1 | A1000000000 |
| 12345678901 | 0 | 12345678901 |

字母同時告訴你後面有幾位數，所以不會混淆。

## 裡世界：走出代號、傳送

- 每個角色在自己的世界蓋建築，並自訂**走法**：
  - 繞某棟建築一圈是 J，繞兩圈是 I……
  - 從甲走到乙是 1，走到丙是 2……
- 要去找誰，就在自己的世界用自己的走法走出對方的代號。
- 走完出現**白光傳送門**，傳送到對方設定的路上，走到他設定的終點。沿途可以進他的規則屋看看。
- **任何時候**都能傳送過去逛；只有在他的出發點那一微秒抵達終點，才能見面、融合。代號是地址，微秒是約定。
- 表世界不用走：直接輸入代號（例如 J1）。走法表、建築表在表世界先填好，裡世界照表蓋。

## 建築（每張表一棟）

| 建築 | 對應的表 | 來訪者看得到嗎 |
|---|---|---|
| 規則屋 | 規則表、規則版本 | 依可見條件 |
| 難題碑 | 難題表（擱置的留下舊碑） | 依可見條件 |
| 終點台 | 出發點 | 看得到 |
| 融合殿 | 融合紀錄 | 只有參與者 |
| 工坊 | 階段 | 只有參與者 |
| 熱量爐 | 熱量表、每日額度 | 只有自己 |
| 帳房 | 點數紀錄 | 只有自己 |
| 兌換市集 | 兌換預約 | 兌換雙方 |
| 紀錄館 | 出發紀錄、擱置紀錄 | 只有自己 |
| 密室 | 常用尾數 | 只有自己 |
| 信箱 | 待處理 | 只有自己 |

路就是路徑圖；傳送門走完代號才出現。建築同時是走法的地標。原型先蓋五棟：規則屋、難題碑、終點台、融合殿、工坊。

## 維護方式：玩家自己維護

- **不審核**：世界壞了，別人就不來，合作意願自然下降。
- 點數綁定發出者，只能換發出者的能量點；自己發給自己的點數沒有價值，作弊只騙到自己。
- 只有兩件事要做對，都由程式自動檢查：
  1. **共同格式與簽章**：大家用同一種資料格式；每筆點數有發出者的簽章，沒人能冒用別人發點數。
  2. **世界只能是資料，不能是程式**：傳送過去時只讀對方的資料（表格、建築、走法、規則），畫面由自己的程式畫，對方的程式碼永遠不在你的裝置上跑。
- 每個世界可以把快照放在主人自己的雲端空間，主人不在線也能逛；只有見面、融合需要雙方在線。
- 玩家可以用自己的 AI（自己的 API key）蓋世界、修東西，費用由玩家自己付。

## 技術與規模

- 不做 3A，做 **3D、小規模、手機和 Steam 都能玩**。參考《風之旅人》《Sky 光遇》《紀念碑谷》：範圍小、把相遇的瞬間做到極致。
- 引擎：**Three.js（網頁 3D）**。手機點連結就能測；之後包裝成 Steam 版和手機 App，不用重寫。
- 規則與資料是獨立的一層，畫面是另一層；換引擎只換畫面。

## 成本規劃

| 階段 | 現金支出 |
|---|---|
| 原型 | 0 元 |
| 找熟人玩 | 網域一年約 500 台幣；網站空間、素材用免費的 |
| 正式上架 | Steam 100 美金（營收滿 1,000 美金退還）、Google Play 25 美金一次、App Store 每年 99 美金 |
| 上架以後 | 平台抽成；通訊錄和連線中繼隨玩家數增加 |

最大的成本是開發時間。
