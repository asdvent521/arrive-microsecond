# v7 改版計畫：兩種介面，同一套功能

照 [DESIGN.md](DESIGN.md) 第 7 節，把 v6 的介面拆成兩種：**裡世界像遊戲、表世界是簡單的 Excel 表**。功能完全一樣，規則層不動。

## 原則

- 新資料夾 `v7/`，從 `v6/` 複製；`core.js` 規則層**原封不動**沿用（只能加，不能改既有規則），`world.js` 沿用。
- 兩種介面各自一個檔案：`game.js`（裡世界）、`sheet.js`（表世界）；兩者只呼叫 `CORE`，彼此不互相呼叫。共用的狀態與存檔放在 `app.js`。
- **功能對照表（DESIGN.md 7-3）每一列兩邊都要做得到**，測試要逐列驗證。
- 右上角一個切換鈕「表 ⇄ 裡」，切換時停在同一件事上（同一個角色、同一個功能）。
- 手機優先（寬 360px 也要好用）。Three.js 照 v6 打包進單一 HTML。

## 裡世界（`game.js`）

**畫面**
- 3D 全螢幕。HUD 只有：
  - 左上：名牌（代號、名字）＋**能量條**（今天還能給多少點 / 每天的點）。
  - 右上：「表 ⇄ 裡」切換鈕；那一微秒前 60 秒內才出現倒數。
  - 上方中間一行**任務提示**：從 v6「下一步」的步驟算出目前該做的事，例如「下一步：開對接時段 → 走到終點台」。點一下可以展開完整清單。
  - 走代號時，代號一個字一個字浮在名牌下面。
- 不要表格、不要分頁列、不要大段文字。

**互動**
- 點地面走路、點建築走過去、單指拖曳轉鏡頭、兩指縮放（沿用 v6）。
- 到了建築旁，從**底部升起對話框**（高度不超過畫面 40%，不蓋住建築）：標題「這裡是規則：規則屋」，下面 2–4 個選項按鈕。選項的內容再開一層對話框，像 RPG。
- 各建築的選項：

| 建築 | 別人的 | 自己的 |
|---|---|---|
| 規則屋 | 閱讀規則（分頁翻：用途 → 條件 → 開關與村規，條件用白話）、接受村規 | 閱讀規則；有草稿時「寫規則」 |
| 市集 | 商店清單（名稱、價格、剩幾份），點一項「兌現」 | 上架（只在草稿）、補貨 |
| 終點台 | 時刻表（時段、名額），「預約」 | 開時段、看預約、拒絕（只在空窗且做不到對方要求時） |
| 角色碑 | 每天的點、週期剩多久（用條顯示）、狀態、前身 | 換角色、新角色（一步一步問：名字 → 每天的點 → 週期 → 規則 → 資源）、進出空窗、結束並重創、歷史紀錄 |
| 帳房 | （看不到） | 背包：手上有誰的點、多少、到期日、能不能兌現 |

- **地圖**（右上一個按鈕）：所有角色排成一張圖，一方通的亮、不通的暗，點一個人顯示「怎麼走過去」並開啟地上指引。
- **指引**：要去某個代號時，地上依序亮出光點（繞圈的物件周圍一圈、接著走到的物件），走完一段熄一段。取代 v6 的長句路線說明。
- **建造模式**（只在自己的世界，名牌旁一個「建造」鈕）：點物件 → 對話框：換外觀、換顏色、搬移（再點地面放下）、加門／拿掉門、刪除；「設定走法」：選物件指定繞圈字母、選兩個物件指定數字；「新增地標」。
- **對接那一微秒**：站在對方終點上 → 倒數 → 白光 → 兩個角色並排 → 「交換」對話框：滑桿選給多少（0 到能量條剩下的），確定後能量條往下降、對方的點飛進帳房。錯過就顯示「錯過了那一微秒」。

## 表世界（`sheet.js`）

**畫面**
- 沒有 3D、沒有 HUD。上方一行：工作表名稱＋「表 ⇄ 裡」切換鈕。下方是 Excel 式工作表分頁（可左右滑），用顏色分組。
- **一張工作表只放一張表**。表頭是欄位名稱，左邊小小的列號，第一欄凍結，可以左右滑。不放欄字母、不放 fx 編輯列、不放說明段落。
- 按鈕在格子裡；代號、功能點、時段、點數都是連結，點了跳到對應工作表那一列並閃一下；左上「←」返回。
- 新增一筆：表格最下面一列直接填。

**工作表**（順序與分組）

| 分組 | 工作表 |
|---|---|
| 待辦 | 待辦 |
| 我的（藍） | 角色、規則用途、對接條件、開關與村規、資源、世界、走法（繞圈）、走法（走到） |
| 找人（綠） | 我可以去找、可能來找我、查資源、可預約時段、我開的時段、我預約的 |
| 帳本（金） | 對接紀錄、點數、兌現、紀錄 |
| — | 說明（所有工作表的說明集中在這裡） |

- **我預約的**多一欄「到場」：勾了等於站在對方終點上；那一微秒到時照規則層判定（沒勾就錯過）。給點欄在同一列。
- **看別人的東西**：規則、資源、時段工作表上方一個「看誰」下拉；預設看自己。

## 規則層只加不改

- 加 `presence`：表世界「到場」的狀態，畫面層每格把「站在終點上」或「勾了到場」合成同一個判定送進 `dock()`。
- 任務提示與待辦共用同一個函式（從 v6 sheets.js 的下一步搬到 `app.js`）。

## 測試

- `core.test.js` 沿用，全部要過。
- **對照測試** `t_parity.js`：DESIGN.md 7-3 的每一列，在裡世界做一次、在表世界做一次，兩邊的結果（state）要一樣。
- 裡世界：沒有任何表格元素；對話框不超過畫面 40%；能量條隨給點下降；指引光點出現；建造模式改外觀後走法照樣有效；那一微秒對接與錯過。
- 表世界：每張工作表只有一張表；沒有 3D；「到場」對接成功與錯過；連結跳轉與返回。
- 切換：在裡世界站在 J2 規則屋 → 切到表世界是 J2 的規則用途；反過來在表世界看 J3 的資源 → 切到裡世界顯示怎麼走去 J3。
- 擋掉 Three.js 時：表世界完整可用，裡世界顯示「3D 引擎沒載入」。

## 這一版不做

多人連線、三層資料存放、簽章、驗證碼、聯絡方式加密、紙條與動作交流、內部空間的建造模式（內部沿用 v6 的表世界編輯）。
