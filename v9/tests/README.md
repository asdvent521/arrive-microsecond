# v9 測試（第 4 輪）

一次跑一個檔。所有按鈕都用手指按：先確認 `elementFromPoint` 打到的就是那個按鈕，再點那個座標（`lib.js`）。換表也是按下方的組、上方的表。畫面測試預設手機轉橫（780×360）。達秒屋的 3D 用 swiftshader 畫；點 3D 裡的東西（磚、門、地上的格子、擺設）也一樣：先確認那一點是畫布、而且打到的就是那樣東西（門、某一天的磚、某一塊日曆、預告框、某一塊方塊的某一面、地上某一格），再點那個座標（`tap3d`）。`fresh()` 預設用不帶過去紀錄的示範資料，`fresh({ raw: true })` 是真的第一次打開（示範角色帶著好幾百天的紀錄）。
